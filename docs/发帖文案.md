## 中文版（V2EX / 掘金）

**标题**：我做了个「替你逛 GitHub」的开源项目发现工具（Windows/macOS 双平台）

**正文**：

GitHub 上有几十万个免费开源好工具，但大多数人被英语界面、命令行、真假难辨的质量挡在门外。

我做了个叫 **STARPICK** 的工具，思路是「把 GitHub 逛成应用商店」：

- **按分类逛**：影视 / 游戏 / 开发 / AI工具 / 效率工具等 12 大分类，190 个中英关键词持续召回
- **四维筛选**：分类 + 语言（中文友好）+ 平台（Win/mac/Linux/Android）+ 新增，自由叠加
- **看得懂再下载**：每个项目标注平台支持、系统要求、中文友好度；点「下载版本」按当前系统列出全部安装包，国内镜像加速 + 原地址双通道
- **站内看详情**：完整 README 不跳 GitHub，自带中文版本默认展示，多语言一键切换
- **中英文界面**：一键切换界面语言
- **自己掌控采集**：手动触发、按分类采、可选阈值，无定时任务

技术栈：FastAPI + SQLite + Vue3，本地部署，数据完全在你机器上。

Windows / macOS 安装包都有，下载即用：[GitHub Releases](https://github.com/Geoff-WSX/starpick/releases/latest)

项目开源：[github.com/Geoff-WSX/starpick](https://github.com/Geoff-WSX/starpick)

如果你也烦「想找工具但不会逛 GitHub」，欢迎试试，也欢迎提建议。

## 英文版（r/selfhosted / r/opensource）

**标题**：I built a "GitHub discovery" tool that turns GitHub into an app store — browse by category/platform/language, with local-first data

**正文**：

GitHub has hundreds of thousands of great open-source tools, but most people are put off by English UIs, CLIs, and uncertain quality.

I built **STARPICK**, a self-hosted tool that curates GitHub for you:

- **Browse by category**: movies, games, dev tools, AI tools, productivity, etc. (12 categories, 190 keywords)
- **Filter by platform**: Windows / macOS / Linux / Android / iOS / Web / Docker
- **Understand before downloading**: each project shows platform support, system requirements, and Chinese-friendliness; download links with mirror acceleration
- **Read details in-app**: full README without leaving, multi-language switching
- **Bilingual UI**: one-click switch between Chinese and English
- **Manual collection**: you trigger collection yourself, no background cron jobs

Stack: FastAPI + SQLite + Vue3, fully local — your data never leaves your machine.

Releases for Windows & macOS: [GitHub Releases](https://github.com/Geoff-WSX/starpick/releases/latest)

Open source: [github.com/Geoff-WSX/starpick](https://github.com/Geoff-WSX/starpick)

Designed primarily for Chinese users. Feedback welcome!
