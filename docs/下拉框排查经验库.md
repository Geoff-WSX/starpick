# 下拉框"打不开/值乱跳"排查经验库

> 记录：2026-10-16 ｜ 项目：STARPICK 拾星 ｜ 适用：自绘下拉（BaseSelect）及类似弹窗交互
> 用途：以后遇到"下拉框打不开、点一下值就跳、菜单一闪而过"等问题，先查本库再排查。

---

## 一、症状 → 快速定位表

| 症状 | 最可能原因 | 修复 | 验证方式 |
|---|---|---|---|
| 点击下拉，**值直接变成第一项**，菜单不出现；**别的弹窗正常** | `<label>` 包裹了自绘下拉 → label 激活行为把点击转发给菜单第一项按钮 | 把 `<label>` 改成 `<div>`（输入框的 label 保留） | 真实 CDP 点击，值不应跳变 |
| 点击下拉，菜单**打开后瞬间关闭**（像没反应） | 滚动监听过于激进：任何 scroll 事件（含浏览器**滚动锚定**的微滚动）都关闭菜单 | 只在菜单**完全滚出可视区**才收起 | 打开菜单后派发微滚动，菜单应保留 |
| 点了没反应，**自动化测试却正常** | 合成事件（`dispatchEvent`）不经过浏览器真实输入管线（label 激活、滚动锚定） | 用**真实 CDP 点击**（click_xy）复现 | click_xy 结果应与用户一致，而非合成事件 |
| 修改后用户**刷新仍旧行为** | `index.html` 无缓存控制头，浏览器沿用旧 JS | SPA fallback 响应加 `Cache-Control: no-cache` | curl 检查响应头 |
| 窄视口下菜单被裁掉一半 | 弹窗内部可滚动（`overflow-y: auto`），向下展开的菜单被裁 | 菜单空间不足时**向上翻转**（nextTick 测量） | 窄视口截图确认菜单完整 |
| 点选项后**菜单又弹回来** | 选项 click 冒泡到外层 toggle，先关后开 | 选项加 `@click.stop` | 选中后 open 应为 false |

## 二、根本机制（三个关键知识点）

### 1. label 激活行为（本次根因，最具迷惑性）
- **机制**：`<label>` 包裹任意内容时，浏览器（真实点击）会把激活行为转发给标签内**第一个 labelable 元素**（button/input/select…）。
- **坑**：自绘下拉平时内部无 button；**菜单打开瞬间渲染出第一个 `.bs-option` button** → 点击被转发命中它 → `pick()` 第一项 → 菜单立即关闭。用户感知："点一下值就变了，菜单没弹出来"。
- **为什么测不出来**：合成 `dispatchEvent` 不触发浏览器的 label 激活行为。
- **判别信号**：症状只出现在**被 label 包裹**的下拉（本项目：采集中心），不出现的在普通容器（收藏弹窗）。
- **规则**：**自绘交互组件（div+button）永远不要用 `<label>` 包裹**；label 只用于原生表单控件（input/select）的语义关联。

### 2. 滚动锚定（scroll anchoring）
- **机制**：浏览器在 DOM 插入/布局变化时自动微调滚动位置（防跳动），会派发 scroll 事件。
- **坑**：菜单渲染（DOM 插入）触发滚动锚定 → 若滚动监听"任何 scroll 都关菜单"，菜单在打开瞬间被误关。
- **规则**：滚动收起菜单必须判断"菜单是否真的滚出可视区"，而不是"发生了滚动"。
- **补充**：`scroll` 事件**不冒泡**——监听 document 收不到弹窗内部滚动，必须直接挂在滚动容器上（打开时动态挂、关闭时移除）。

### 3. 合成事件 ≠ 真实点击
- 自动化验证自绘交互（下拉、弹层、hover）**必须走真实输入路径**（CDP mouse 事件 / click_xy），合成 `dispatchEvent` 只验证 handler 逻辑，不验证浏览器行为。
- 本项目环境：`mac_computer_use_tool`（plane=bu）的 `click_xy` 是真实 CDP 点击；注意其可能派发两次输入（二次点击会命中菜单第一项——这正是"值跳第一项"的自动化再现，也是排查线索）。

## 三、本项目 BaseSelect 组件现状（2026-10-16）

- 组件：`frontend/src/components/BaseSelect.vue`（自绘菜单，视觉对齐首页排序下拉）
- 已包含的稳定性修复：
  1. 选项 `@click.stop`（防冒泡弹回）
  2. `menu-up` 向上翻转（防窄视口裁剪，nextTick 测量容器）
  3. 滚动仅在菜单**完全滚出可视区**才收起
  4. scroll 直接挂滚动容器 + window（打开时挂、关闭时卸）
  5. 外部点击关闭（onDocClick + closest 判断）
- 调用方：`CollectModal.vue`（3 处，**div 包裹**）、`FavoritesModal.vue`（1 处，div 包裹）
- ⚠️ 约束：**不要再把 BaseSelect 放回 `<label>` 内**；新加下拉时用 `<div class="param-item">`。

## 四、排查方法论（可复用步骤）

1. **先复现**：用真实 CDP 点击（click_xy）复现用户现象；合成事件通过≠没问题。
2. **找差异**：对比"出问题的弹窗"与"正常的弹窗"的 DOM 结构差异（本项目：label vs div）。
3. **验证机制**：确认差异点对应的浏览器机制（label 激活行为）→ 修改 → 真实点击验证。
4. **回归清单**（改下拉后必测）：
   - [ ] 三个采集下拉真实点击：菜单打开且停留、值不跳变
   - [ ] 选中选项后菜单关闭、值正确
   - [ ] 窄视口菜单不被裁剪（或向上翻转）
   - [ ] 微滚动不误关菜单
   - [ ] 收藏弹窗排序下拉正常
   - [ ] 日夜模式菜单配色正常
   - [ ] 服务引用最新构建 hash + index.html 返回 no-cache
