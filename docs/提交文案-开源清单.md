### 😳 Explain why it should be added

```
STARPICK is an open-source macOS desktop app for discovering and installing software from
GitHub. It indexes 2000+ starred repositories across 12 categories, extracts Chinese
descriptions and system requirements automatically, lists every release asset per platform
(Windows/macOS/Linux/Android/iOS/Web/Docker), and serves READMEs in-site with multilingual
switching instead of bouncing users to GitHub.

It fits the "开发者实用工具" section: it is a developer-facing curation tool that also works
for non-technical users, since the desktop build ships as a double-click installer and
requires no CLI.

MIT licensed, distributed as both a .dmg and a Windows installer via GitHub Releases.
Backend is FastAPI + SQLite, frontend Vue 3 — no cloud dependency, everything runs locally.
```

## 二、HelloGitHub（18.7 万星，中文开源月刊）


### 类别

选 **Python**

### 项目标题（≤50 字）

```
一个像刷应用商店一样逛 GitHub 的开源项目发现工具
```

### 项目描述（32–256 字，本稿 249 字）

```
STARPICK 把 GitHub 上几十万个开源项目变成可以「逛」的界面。它按影视、游戏、开发、AI 工具等 12 个分类持续采集高星项目，自动提取中文简介、系统要求、支持的平台和全部安装包版本；README 支持多语言切换，图片和下载直链走国内镜像加速。配上桌面版后，非技术用户不需要知道什么是仓库、release 或命令行，按分类浏览、点「下载」就装好一个软件。对中文用户还提供「中文友好」筛选，一键只看有中文文档的项目。
```

### 亮点

```
大多数 GitHub 导航站只是把项目名堆成列表，STARPICK 多做了三件事：

1. 每个项目标注真实系统要求和完整安装包清单——Kazumi 这类有 9 个平台版本的项目会把全部列出，而不是只给一个「去 Releases」的链接。

2. README 抓进站内直接看，不跳转 GitHub，图片自动走镜像，多语言版本（中/英/日等，全库 375 个语言版本）一键切换。

3. 分类采集带本地复检和排除词。这一步是踩坑踩出来的：裸词「emulator」会把终端模拟器（alacritty、ghostty 各 6 万星）归进「游戏」分类，实测 140 个项目里 47 个是这种误判。后来给分类加了负关键词机制（`!terminal`、`!game engine` 等）才解决。

桌面版打包成双击即装的安装包，Windows 和 macOS 都有。整个项目本地运行，不依赖任何云服务。
```
